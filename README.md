# Power Pose Testing

Power Pose Testing is an iOS application developed in **Swift** during **Summer 2024** for a research project investigating the effects of power posing on human performance.

The app provides a standardized platform for administering a variety of brain and performance-based tests and collecting participants' results for research analysis.

## About the Project

This application was developed as part of a research study examining whether adopting different physical poses could affect participants' performance on a series of tests.

The app was designed to make the experimental process more consistent by presenting each participant with the same testing environment and recording their performance across multiple tasks.

## Features

* Multiple performance and brain-based tests
* Standardized testing interface for research participants
* Collection of participant test results
* iOS interface built natively with Swift
* Designed specifically for use in a controlled research study

## Tech Stack

* **Language:** Swift
* **Platform:** iOS
* **Development:** Xcode
* **Year:** Summer 2024
